# Code of conduct

## The short version

Be decent. Assume the person on the other end is trying to read a disk that was
manufactured before most software people were writing software, on a drive whose
belt has been stretching since 1986.

## What is expected

Technical disagreement is welcome and is most of what a project like this is.
Take it to the evidence: run the thing, read the bytes, say what you measured.
Several conclusions here reversed under measurement, and every one of them
reversed because somebody counted rather than argued.

Assume good faith about mistakes. A wrong checksum, a wrong offset or a wrong
claim is a thing to correct, not a thing to be scored against somebody.

## What is not

Personal attacks, harassment, or making somebody's identity the subject.
Deliberate bad faith: reopening a settled question without new evidence, or
arguing a point already answered by a measurement in the thread.

## Scope

Issues, pull requests, discussions and commit messages on this repository.

## Enforcement

Report it through
[GitHub's private vulnerability reporting](https://github.com/gufranco/famicom-disk-system-python/security/advisories/new)
when it should stay private, and in the thread itself when it should not. This
is a small project with one maintainer, so the realistic response is that a
comment gets removed, or a person gets blocked, and that is the whole
enforcement ladder.
